# IDvACC Vatglasses Repository  

### AOR  
IDvACC is Responsible for providing service to the following Areas:  
- WIIF FIR excluding YPXM
- WAAF FIR Including Timor-Leste Airspace

### Files  

The following Files in the vatglasses-data repository are owned by IDvACC:  
- wa.json
- wi.json
- wp.json

Due to existing LOA(s), some parts of IDvACC Airspace is defined in the following file(s):
- ws.json
